UseIt - Rental App

Overview

UseIt is an Android rental application concept designed to help people
find and rent useful items at affordable daily rates instead of buying
them.

Tagline: Rent it. Use it. Return it.

Project Status

This project is currently under development. The Android project has
been created and tested with an initial build and installation. The home
screen, additional app screens, and backend integration are planned for
upcoming development.

Planned Features

-   Browse rental products and categories
-   Search for tools, home equipment, electronics, and outdoor items
-   Discover products by city, PIN code, or nearby location
-   View product details, rental prices, ratings, and availability
-   Save favourite products
-   Book rentals
-   Choose pickup or home delivery
-   View and manage rental bookings
-   User profile and authentication
-   Admin-managed product inventory

Technology Stack

-   Language: Kotlin
-   Platform: Android
-   UI: Android XML layouts
-   Backend: Firebase (planned)
-   Database and storage: Cloud Firestore and Firebase Storage (planned)
-   Authentication: Firebase Authentication (planned)

Design Direction

The planned interface uses a clean, minimal design with: - Warm
cream/off-white backgrounds - Deep green accents - Simple typography and
rounded product cards - A bottom navigation bar with Explore, Saved,
Rentals, and Profile

Project Setup

1.  Clone or download this repository.
2.  Open the project in Android Studio.
3.  Allow Gradle to sync.
4.  Connect an Android device or start an emulator.
5.  Run the app using the Android Studio Run button.

Note: Setup instructions may change as the project develops.

Current Development Notes

-   The app is being built step by step.
-   Backend services and the complete booking flow are not yet
    implemented.
-   Product examples and prices shown in design references are
    illustrative and may change.
